DONIZO TRUTH ENGINE - PROJECT SUMMARY

WHAT WE'RE BUILDING:
A pricing engine that learns the "true price" of construction materials by combining 3 sources: historical data, supplier quotes, and human decisions. Think of it as a smart pricing brain that gets better over time.

KEY FEATURES:
- Processes price signals from multiple conflicting sources
- Learns patterns from validated human decisions (keeps last 5, uses median)
- Applies learned "bias" to future supplier quotes
- Safely decays old knowledge (prices older than 7 days lose relevance)
- Blocks anomalies (rejects prices >150% of baseline)
- 100% auditable - every decision is logged with full reasoning

TECHNICAL APPROACH:
- Language: Python
- All money calculations in cents (integers only - no rounding errors)
- Deterministic system (same inputs = exact same outputs, provable via hash)
- Event sourcing architecture with state persistence
- Replay capability for debugging and verification

DELIVERABLES:
1. CLI tool with run and replay modes
2. Synthetic test data (1000+ events showing learning curve)
3. Docker setup for easy deployment
4. Full test suite with edge cases
5. Complete documentation

TIMELINE:
7 days broken down as:
- Days 1-2: Foundation (data models, parsing, CLI setup)
- Days 3-4: Core pricing logic (5 decision rules)
- Day 5: State management and audit trails
- Day 6: Testing and synthetic data
- Day 7: Polish and documentation

WHY THIS IS INTERESTING:
This isn't just a coding test - it's a production-grade financial system with ML elements. The challenge is maintaining strict financial integrity (no calculation errors) while building a learning system that's fully explainable and auditable.
